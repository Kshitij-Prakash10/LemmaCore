# Requests between agents

Use this folder when you need something from a path you do not own.

1. Create a **new** file: `YYYYMMDD-HHMM-<agent>-<short-title>.md`. Never edit an existing file here.
2. Write: what you need, why, what you will do meanwhile, and how urgent it is.
3. The owner answers with a new file named `YYYYMMDD-HHMM-<agent>-<short-title>-reply.md`.
4. Humans can read everything here to settle disputes.

New files never cause git conflicts, which is the point.
